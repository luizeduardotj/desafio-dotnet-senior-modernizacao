# feat(consulta): primeira versão da API REST de consulta de NFS-e

**PR #212** · autor: @marcelo.legado · base: `main` ← `feat/api-consulta-nfse`

## O que eu fiz

Pessoal, segue a primeira versão da API de consulta de NFS-e em .NET 8 (minimal API). A ideia é tirar do WebForms/ASMX as consultas que hoje os sistemas parceiros fazem direto no nosso `.asmx` e expor isso como REST, já que o pessoal de fora vive pedindo.

Criei o projeto `src/Nfse.Consulta.Api` com:

- `GET /api/v1/nfse/{prestador}/{numero}` — consulta uma nota
- `GET /api/v1/tomadores/{documento}/nfse?inicio=&fim=&pagina=&tamanho=&situacao=` — lista as notas de um tomador num período, paginado
- `POST /api/v1/nfse/{prestador}/{numero}/cancelamento` — cancela uma nota (valida prazo e se o prestador está regular na Receita antes)

Acesso ao Oracle com `Oracle.ManagedDataAccess.Core` e ADO.NET puro (sem ORM, igual a gente fazia no ADO.NET do sistema antigo, achei mais seguro de começar assim). A situação cadastral do prestador vem do serviço da Receita que já usamos internamente. Coloquei um cache simples pra não bater no serviço toda hora.

Também deixei um projeto de testes com `WebApplicationFactory` em `tests/Nfse.Consulta.Tests`.

## Como testei

Testei localmente apontando pro banco de homologação, consultei algumas notas, listei por tomador e cancelei uma nota de teste. **Testei localmente, funcionando.** Os testes passam aqui também.
